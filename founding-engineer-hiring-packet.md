# Founding Engineer Hiring Packet

## Role Brief
- Title: Founding Engineer
- Mission: Build the first production-ready product increment, establish engineering foundations, and co-own delivery velocity with the CEO.
- Stage fit: High-autonomy builder comfortable with ambiguous scope, fast iteration, and direct customer feedback loops.

## Scorecard
Use a 1-4 scale per competency:
- 1: does not meet baseline
- 2: partially meets baseline
- 3: meets baseline
- 4: exceeds baseline

Minimum hiring bar:
- No score below 2 in any core competency.
- Average score across core competencies >= 3.2.
- Technical depth and ownership must both be >= 3.

### Core Competencies
1. End-to-end product engineering
- Designs, implements, tests, and ships features independently.
- Makes pragmatic tradeoffs between speed, quality, and scope.

2. System design and architecture judgment
- Chooses simple, maintainable architecture for early-stage constraints.
- Anticipates scaling and reliability needs without premature complexity.

3. Ownership and execution
- Drives work without waiting for detailed instructions.
- Surfaces risks early and proposes clear mitigation.

4. Collaboration and communication
- Communicates decisions, assumptions, and progress clearly.
- Works effectively with non-engineering stakeholders.

5. Startup adaptability
- Operates effectively in ambiguity and changing priorities.
- Demonstrates resilience and bias toward action.

6. Product and customer mindset
- Connects technical decisions to user impact.
- Uses customer feedback to prioritize and refine implementation.

### Optional Strength Signals
- Prior 0->1 build experience.
- Experience establishing CI/CD, observability, and basic security practices.
- Mentoring and future team-building capability.

## Interview Loop
Target timeline: 7-10 calendar days from first screen to decision.

### Stage 1: Recruiter/CEO screen (30 min)
Objective:
- Validate motivation, startup fit, communication clarity, compensation alignment, and availability.

Pass criteria:
- Clear reasons for joining at founding stage.
- Evidence of ownership and delivery in prior roles.

### Stage 2: Technical deep-dive (60 min)
Format:
- Candidate walks through a shipped project and explains architecture, tradeoffs, incidents, and outcomes.

Assess:
- Depth of understanding, ownership boundaries, debugging rigor, and design judgment.

Pass criteria:
- Demonstrates direct impact and coherent tradeoff reasoning.

### Stage 3: Practical coding exercise (90 min)
Format:
- Realistic implementation task (small feature + tests + brief README).
- Evaluated on correctness, clarity, testing quality, and delivery pace.

Assess:
- Code quality, decomposition, test strategy, and communication.

Pass criteria:
- Functional solution with clear structure and baseline tests.

### Stage 4: System design for MVP evolution (60 min)
Format:
- Design session on scaling current MVP architecture over next 6-12 months.

Assess:
- Scope control, reliability strategy, data modeling, observability plan, and migration thinking.

Pass criteria:
- Practical design aligned to stage; avoids both under-design and over-engineering.

### Stage 5: CEO collaboration and values interview (45 min)
Objective:
- Validate working style, decision principles, conflict handling, and long-term alignment.

Pass criteria:
- High trust potential, strong accountability, and evidence of constructive disagreement.

### Stage 6: References (2 calls, 20-30 min each)
Objective:
- Confirm ownership, consistency of delivery, collaboration quality, and integrity.

Pass criteria:
- Reference feedback corroborates interview performance and leadership potential.

## Decision Rubric
### Decision categories
- Strong Hire
- Hire
- Lean Hire
- No Hire

### Rule-based decision logic
1. Immediate No Hire triggers
- Any integrity concern.
- Any core competency scored 1 by two or more interviewers.
- Repeated inability to explain own technical decisions.

2. Hire threshold
- Average core score >= 3.2.
- At least two interviewers recommend Hire or better.
- No unresolved material concerns from references.

3. Lean Hire conditions
- Average core score between 2.9 and 3.19.
- Gaps are coachable within one quarter.
- Explicit 30/60/90 onboarding risk plan is defined.

4. Strong Hire conditions
- Average core score >= 3.6.
- Clear evidence of 0->1 ownership and force-multiplier behavior.
- High confidence in cross-functional execution with minimal oversight.

### Debrief protocol
- All interviewers submit independent written feedback before group discussion.
- Debrief sequence: evidence review -> score alignment -> risk discussion -> final recommendation.
- Final decision owner: CEO.
- In case of split feedback, default to No Hire unless concerns are clearly mitigated with evidence.

## Offer and Onboarding Guardrails
- Offer window target: within 24 hours after final debrief.
- Include explicit first-90-day success metrics in offer discussion.
- If accepted, kickoff should include:
  - 30-day deliverables,
  - MVP backlog ownership boundaries,
  - release cadence and communication expectations.
